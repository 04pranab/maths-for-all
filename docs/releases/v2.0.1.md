# Maths for All v2.0.1

**Release type:** Patch  
**Base:** v2.0.0 stable educational baseline  
**Release date:** 25 September 2026  
**Tag:** `v2.0.1`

## Summary

v2.0.1 is a hardening release focused on privacy, keyboard accessibility, modal behaviour, documentation quality, licensing, and regression testing.

No new research database or production authentication backend is introduced by this release.

## Included

### Privacy
- explicit research opt-in remains mandatory;
- initial consent cannot be bypassed with Escape;
- privacy and research-data policy is reachable without login;
- changing research consent to No purges locally stored research events;
- policy now includes an accountability and compliance declaration.

### Accessibility
- authentication and research dialogs receive keyboard focus when opened;
- dismissible overlays can be closed with Escape;
- focus returns to the invoking control;
- Tab and Shift+Tab remain inside the active modal;
- visible keyboard focus remains enabled;
- existing reduced-motion and touch-accessibility support is retained.

### Security and reliability
- hardened local session behaviour from PR #17 is retained;
- malformed, expired, and account-mismatched sessions are rejected;
- browser stress testing covers all five game modules;
- static-resource and runtime-error checks remain in CI.

### Documentation and licensing
- cleaned `README.md`;
- cleaned `CHANGELOG.md`;
- rebuilt `ONGOING.md` as the engineering record;
- updated `AI_USAGE.md`;
- updated the custom responsible-use license;
- bumped `VERSION` to `2.0.1`.

## Scope boundary

The following remain outside v2.0.1:
- production server-side authentication;
- production Google OAuth;
- email verification backend;
- research database infrastructure;
- server-side research API.

Those remain planned for v2.5.0 and v3.0.0 respectively.
