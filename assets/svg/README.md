# Maths for All SVG Asset Library

This directory contains the small set of mathematical artwork used on the five game cards.

## Current assets

| File | Use |
|---|---|
| number-cloud.svg | Arithmetic Quiz card |
| graph-vine.svg | Math Racing card |
| abacus-bloom.svg | Sudoku Challenge card |
| geometry-garden.svg | Shape Fitting card |
| compass-star.svg | Slab Maths card |

The artwork is presentation-only. It must not contain essential instructions, consent information, analytics, authentication, or research behaviour.

Keep the SVGs local, lightweight, dependency-free, and accessible when embedded as decorative HTML artwork. Use an empty alt value and role="presentation".

Avoid embedded scripts, external dependencies, large raster payloads, and unnecessary path complexity.
