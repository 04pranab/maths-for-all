# AI-Assisted Development Record

**Project:** Maths for All  
**Repository:** `04pranab/maths-for-all`  
**Author:** Om Pranab Mohanty  
**Record date:** 6 October 2026

## Purpose

This document records the use of AI-assisted development tools in Maths for All. It exists for transparency and does not transfer responsibility for the project from the human author to an AI system.

## Tools used

The project has used:

- **ChatGPT** for software design discussion, implementation assistance, debugging, test design, documentation drafting, code review support, and release planning.
- **Claude** for software design and implementation assistance during development.

The exact contribution of an AI system can vary by file and development task. The repository history remains the authoritative record of what was actually committed.

## Human responsibility

The project author is responsible for:

- deciding which suggestions are accepted;
- reviewing generated or AI-assisted code;
- checking educational behavior and accessibility;
- testing changes before treating them as part of the project;
- reviewing privacy and research-data implications;
- deciding when a feature is ready for physical learner testing;
- maintaining the project's documentation, license, and release records.

AI output is treated as development assistance, not as an authority on correctness, accessibility, privacy, law, or educational suitability.

## Testing and verification

AI-assisted changes are not considered complete merely because generated code appears plausible.

Where practical, changes are checked through:

- JavaScript syntax validation;
- browser smoke tests;
- stress and repeated-game tests;
- static-resource checks;
- authentication/session checks;
- research-consent and research-gateway checks;
- responsive and large-text checks;
- manual inspection;
- physical testing of learner-facing game mechanics.

Automated tests do not replace real learner, educator, or assistive-technology evaluation.

## Educational responsibility

The project is designed around:

**Games are the medium. Mathematics is the learning. Human values are the background.**

AI assistance must not be used as a reason to add unnecessary complexity, manipulative scoring, unsafe mechanics, or inaccessible interaction.

Game mechanics are reviewed for their actual learning purpose, not only for whether the software runs.

## Privacy and research responsibility

AI assistance does not change the project's privacy requirements.

Research collection remains explicitly opt-in. Login or account creation is not research consent. The research-data policy and consent-aware implementation remain authoritative.

No AI-generated suggestion may override the repository's documented privacy, security, or responsible-use requirements.

## Provenance

This record is intentionally concise. It does not claim that every line of the repository was generated by AI, nor does it claim that AI systems independently authored the project.

The commit history, issue discussions, pull requests, tests, and release records provide the more detailed engineering history.
